Token Radar ranks 198 pre-token DeFi protocols by implied value — TVL times a sector multiple read off the protocols that already trade, adjusted for seven-day growth, age and chain breadth — and shows a concrete farm plan, with cost and time, for each one. The dashboard is a static page with no network: a sortable, filterable board, a detail view per protocol, and a live-token view set aside with market caps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
